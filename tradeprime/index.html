Personal project · Android app — TradePrime v1.3.3 / Expo · React Native

The AI lives inside the app — not in the cloud.

TradePrime is an Android trading app with a large language model built into the app itself.

A Qwen3 model is downloaded to the phone and runs on-device via llama.rn — no cloud AI is needed for the analysis. Underneath it, a deterministic engine does the actual market maths on live data, a voice agent watches BTC and NIFTY and speaks what it sees, and Telegram signals become local paper orders. Analysis and paper features only — no live-money trading.

Design Principle

“The LLM is not the source of truth for price conditions. Price checks are rule-based — so candle closes, level breaks and retests are repeatable and fast. The LLM explains.”

That split runs through the whole app. The deterministic engine computes every number — trend, levels, stop, targets. The on-device Qwen model only turns that finished analysis into a readable companion explanation, and if the model is missing, the analysis still comes back complete. The AI narrates; it never invents prices.

Feature 01 · Inbuilt On-Device LLM

Local TradePrime AI: a model on the phone itself

In Available Strategies, the original strategy is now Cloud TradePrime AI — and next to it sits Local TradePrime AI, a dedicated screen that fetches live BTC data, runs the deterministic engine, and then asks the on-device Qwen model to explain it. The GGUF model files are intentionally not committed to git — they are downloaded inside the app to the phone's own document storage.

Feature 02 · Deterministic Analysis Engine

The engine does the maths. The LLM does the talking.

The engine pulls live BTCUSDT candles and ticker data from Binance (NIFTY local AI support is also in the app) and computes everything itself: EMA 9/20/50/200, RSI14, ATR14 (+ATR%), VWAP, nearby and major support/resistance, 5m/15m/60m change and volume ratio. Out comes a full trade plan — bias with confidence, market regime, a recommendation (hold long / hold short / wait / trail stop / reduce risk), entry zone, stop loss, targets T1/T2/T3, risk:reward, invalidation, reasons, risk notes and a checklist.

    Feature 03 · Voice Market Agent

    It watches the market — and speaks up

    While the Local TradePrime AI screen is open, the Voice Market Agent scans BTC and NIFTY every 12 seconds (with a keep-awake lock on the screen). A deterministic watcher — 1m candles aggregated into 15m — detects events and reads them aloud through Android text-to-speech. You can also push-to-talk: ask a question out loud, and it is answered from the latest market snapshot by local Qwen, with a deterministic spoken answer as fallback.

    —Press Start Voice Agent to watch the demo watcher detect events and “speak” them here, in order.
    Push-to-talk: spoken questions (via speech recognition) are routed into the latest BTC/NIFTY snapshot and watcher state — local Qwen answers when installed, the deterministic market answer otherwise.

    Toggleable detectors

    Tap to switch detectors on or off — exactly like the panel in the app. The demo watcher only “speaks” events whose detector is on.

    Honest limitation: this version is built for a spare phone keeping the AI screen open during market hours. Always-on microphone and full-duplex conversation (VAD, streaming STT, interruptible speech) are the documented next layer — not yet built.

    Feature 04 · Telegram Signals → Paper Orders

    Your Telegram calls, parsed into paper orders

    TradePrime can monitor one Telegram group or channel through your own bot, parse supported NIFTY / SENSEX CE/PE calls, and create local paper orders. The bot token and your signed server session live in Android SecureStore — never in the APK and never in the SQLite database. Polling runs every five seconds while the app is open and active.

    Feature 05 · The Rest of the App

    More than the AI: a full trading companion

    The local AI sits inside a complete app — copying, analysis, alerts, strategies and a broker connection, with a standalone mode that works without the server.

    👥

    A dedicated Trade Copier screen for following and copying trade setups inside the app.

    📊
    Trade Analyser

    A Trade Analyser screen to review trades after the fact — what was taken, and how it played out.

    🔔
    Price Alerts

    Alerts with a create-alert flow, backed by the API server's strategies / alerts / webhooks support.

    🤖
    Bots & Strategies

    The Available Strategies list — where Cloud TradePrime AI and Local TradePrime AI sit side by side, so the on-device path is a first-class strategy, not a hidden setting.

    💾
    Standalone + Local SQLite

    The app keeps local SQLite storage and works as a standalone Android app without the server — the local AI, paper orders and settings live on the phone.

    🔐
    Upstox Integration

    Pair the phone once with the server, then “Login with Upstox” each trading day. OAuth runs in the broker's own browser flow; the client secret and access token stay server-side — the app only receives connection status and the broker profile. NIFTY execution settings are edited in-app and saved to the server.

    Supporting API server

    Behind the app sits an Express API server with PostgreSQL and Drizzle ORM — it supports strategies, alerts and webhooks, holds the Upstox session server-side, and serves the signed session the phone pairs with. The repo is a pnpm monorepo: mobile app, API server, database schema and generated API client (Orval from the OpenAPI spec) in one workspace.
